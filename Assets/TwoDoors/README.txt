TwoDoors 캐릭터 테스트

실행: Assets/TwoDoors/Scenes/CharacterTest.unity를 열고 Play.
Game 창을 클릭하면 마우스 시점을 조작할 수 있습니다. 화면 비율은 16:9 권장.

WASD 이동 / Shift 달리기 / 마우스 시점 / 좌클릭 공격
1 칼 / 2 권총 / R 재장전 / 3 회복 / 4 또는 F 손전등
Escape 일시정지·재개 / F5 테스트 씬 다시 시작

Prefabs 폴더: Player, Mannequin, Golem, Zombie.
공통 체력·피해·회복·사망: Scripts/Characters/CharacterBase.cs.
적 공통 탐지·추적·근접 공격·애니메이션: EnemyCharacter.cs.
NavMesh가 있는 씬에 적 프리팹을 배치하면 PlayerCharacter를 자동으로 찾습니다.
적 프리팹의 최대 체력, 공격력, 공격 간격, 탐지 거리와 NavMeshAgent 속도를 조절할 수 있습니다.

현재 기본값 (원작 확정 수치가 아닌 테스트용):
목각인형: 체력 100 / 속도 2.3 / 공격력 12
골렘: 체력 350 / 속도 0.65 / 공격력 30
좀비: 체력 120 / 속도 1.35 / 공격력 15
플레이어: 체력 100 / 권총 25 / 칼 20 / 탄창 7 / 예비 탄약 56

모든 적은 대기·이동·공격·사망 Animator 상태가 연결되어 있습니다.
목각인형과 골렘에는 제작한 기본 애니메이션을, 좀비에는 배포된 애니메이션을 적용했습니다.
플레이어 몸체는 목각인형 모델을 재사용한 그림자 전용 모델입니다.
1인칭 손·권총·칼은 간단한 임시 제작 모델이며, 움직임·반동·재장전 동작은 코드로 처리합니다.
모델과 HUD는 참고작과 완전히 동일한 복제가 아닙니다.
문 선택 및 라운드 진행은 이번 캐릭터 테스트에 포함되어 있지 않습니다.
