TwoDoors 캐릭터 테스트

실행: Assets/TwoDoors/Scenes/CharacterTest.unity를 열고 Play.
Game 창을 클릭하면 마우스 시점을 조작할 수 있습니다. 화면 비율은 16:9 권장.

WASD 이동 / Shift 달리기 / 마우스 시점 / 좌클릭 공격
1 칼 / 2 권총 / 3 기관총 / 4 샷건 / 5 마체테 / E 회복약 / F 손전등 / R 재장전
기관총은 좌클릭을 누르고 있으면 연사합니다.
Escape 일시정지·재개 / F5 테스트 씬 다시 시작
G 바라보는 아이템 줍기 (2.8m 이내). Tab 인벤토리 창은 제거했습니다.
화면 하단 단축바에 무기·회복약·손전등 아이콘과 키가 표시됩니다.
미보유 아이콘은 어둡게, 선택한 무기와 켜진 손전등은 청록색으로 강조합니다.
테스트 씬은 칼만 가진 상태로 시작합니다. 시작 지점 앞의 권총·탄약·회복약·손전등을 주워보세요.
탄약 최대 210발, 회복약 최대 9개, 장비는 종류별 1개입니다.
권총을 처음 주우면 7발이 장전되어 있으며, 예비 탄약은 따로 주워 R로 장전합니다.
보유 한도를 초과한 수량은 월드에 남습니다. 최대 체력에서는 회복약이 소모되지 않습니다.
인벤토리는 현재 플레이 세션 동안 유지되며 F5/씬 재시작 시 초기화됩니다.
PickupPistol, PickupAmmo, PickupMedkit, PickupFlashlight 프리팹의 Kind/Amount를 조절해 배치할 수 있습니다.

Prefabs 폴더: Player, Mannequin, Golem, Zombie.
공통 체력·피해·회복·사망: Scripts/Characters/CharacterBase.cs.
적 공통 탐지·추적·근접 공격·애니메이션: EnemyCharacter.cs.
NavMesh가 있는 씬에 적 프리팹을 배치하면 PlayerCharacter를 자동으로 찾습니다.
적 프리팹의 최대 체력, 공격력, 공격 간격, 탐지 거리와 NavMeshAgent 속도를 조절할 수 있습니다.

현재 기본값 (원작 확정 수치가 아닌 테스트용):
목각인형: 체력 150 / 속도 4.2 / 원거리 피해 20 / 사거리 14m / 공격 간격 1.8초
골렘: 체력 500 / 속도 3.2 / 공격력 50
좀비: 체력 200 / 속도 5.76 / 공격력 25
플레이어: 체력 100 / 권총 50 / 칼 50 / 권총 탄창 7
기관총: 피해 25, 0.1초 간격 연사, 탄창 30발.
샷건: 산탄 8발 × 피해 18, 0.9초 간격, 탄창 6발, 사거리 22m.
마체테: 피해 65, 0.7초 간격, 전방 2.8m 부채꼴 다중 타격. 벽이 공격을 막습니다.
총기는 예비 탄약을 공유하며 탄창은 무기마다 별도로 유지합니다.
달리기 속도 9.8, 스테미나 소진 5초 / 완충 5초.
명중 시 적 섬광·짧은 경직·파편, 무기별 반동과 합성 발사음을 적용했습니다.
외곽 벽 충돌 두께를 1.2m로 보강하고 ArenaContainment로 플레이어 이탈을 방지합니다.
기관총·샷건·마체테 픽업 프리팹과 테스트 씬 배치, 입장 보급 이벤트가 추가되었습니다.
단축바에는 회복약 수량과 손전등 ON/OFF도 표시합니다.

모든 적은 대기·이동·공격·사망 Animator 상태가 연결되어 있습니다.
목각인형과 골렘에는 제작한 기본 애니메이션을, 좀비에는 배포된 애니메이션을 적용했습니다.
플레이어 몸체는 목각인형 모델을 재사용한 그림자 전용 모델입니다.
1인칭 손·권총·칼은 간단한 임시 제작 모델이며, 움직임·반동·재장전 동작은 코드로 처리합니다.
모델과 HUD는 참고작과 완전히 동일한 복제가 아닙니다.
문 선택 및 라운드 진행은 이번 캐릭터 테스트에 포함되어 있지 않습니다.
