이벤트 밸런스 조정 — Game.unity / StagesV2

기준: 회복약 1개 = 체력 35, 탄창 7발, 권총 피해 25.
즉시 통과 이벤트에서 체력을 지불한 뒤 회복약으로 비용 이상을 회복하는 구성을 제거했습니다.
체력·탄약·시간·전투 위험은 서로 다른 자원이므로 선택은 현재 체력/보유량과 전투 실력에 따라 달라집니다.

1. 무장할 대가
빨강: 체력 -30, 권총 + 예비 탄약 28, 즉시 통과.
파랑: 목각인형 5마리 / 25초. 권총 + 예비 탄약 7, 통과 탄약 14.
고정 체력 비용과 전투 위험 중 선택. 빨강만 대량 보급을 받던 차이를 축소.

2. 떼거리 vs 공성전
빨강: 목각인형 9마리 / 18초, 회복약 보상 없음.
파랑: 골렘 4마리 / 55초, 회복약 보상 없음.
두 문 모두 회복약 보상 없이, 빠른 적의 밀집 압박과 느리지만 단단한 적의 긴 압박 중 선택.

3. 빛을 살 것인가
빨강: 정전 + 목각인형 7마리 / 30초, 손전등 지급, 통과 탄약 14.
파랑: 체력 -35, 즉시 통과. 보급 없음.
어둠 속 전투 보상을 70발에서 14발로 낮춤.

4. 야전 병원
빨강: 골렘 3 + 목각인형 2마리 / 40초, 구역 안에서 초당 8 회복. 이벤트 동안 누적 회복량 제한 없음 (최대 체력은 유지).
파랑: 체력 -20, 탄약 21, 즉시 통과. 회복약 지급 제거.
회복을 원하면 전투 중 좁은 회복 구역을 지켜야 하고, 안전한 통과는 체력을 잃음.

5. 보급품 통행료
빨강: 회복약 2개 지불(회복 가치 70), 다음 단계 건너뛰기. 부족하면 체력 -75.
파랑: 골렘 3 + 목각인형 5마리 / 50초, 통과 회복약 1.
부족할 때 체력 50만 지불해 회복약 2개보다 싸게 이용하던 대체 비용 수정.

6. 탄약 환전소
빨강: 예비 탄약 28 지불, 회복약 1. 부족하면 체력 -50 후 회복약 1(전부 회복해도 순손실 15).
파랑: 목각인형 7 + 좀비 2마리 / 40초, 통과 탄약 35. 입장 탄약 없음.
탄약을 회복으로 교환하거나, 전투를 감수해 탄약을 확보하는 선택.

7. 달리거나 지불하거나
빨강: 정전 + 목각인형 7 + 골렘 1, 손전등 지급. 버튼 3개 또는 적 전멸.
파랑: 체력 -40, 즉시 통과. 탄약/회복약 보상 제거.

8. 피의 보급 상자
빨강: 체력 -45, 탄약 42, 즉시 통과. 회복약 지급 제거.
파랑: 좀비 2 + 골렘 3 + 목각인형 5마리 / 60초, 통과 탄약 28.
고정 체력 지불로 탄약을 더 받거나 전투 위험으로 체력을 보존할 기회를 얻음.

9. 최후의 탈출
빨강: 회복약 2개 지불(회복 가치 70), 즉시 탈출. 부족하면 체력 -80.
파랑: 골렘 4 + 목각인형 6마리 / 70초, 입장 탄약 14, 생존/전멸 탈출.
끝까지 회복약을 아껴서 안전하게 탈출하거나 최종 전투를 선택.

공통: 적 전원 처치 또는 제한 시간 종료 중 먼저 충족하면 통과.
버튼 방은 버튼 3개 또는 전멸이며 시간 제한 없음.
아이템 지급은 인벤토리 한도까지. 입장 비용으로 사망하면 보상/통과 없음.
중단/사망에는 통과 보상 없음. 거래 탄약은 장전 탄약이 아닌 예비 탄약.

검증 메뉴: Tools > TwoDoors > Validate Event Balance.
아이템 충분/부족 양쪽에서 즉시 순회복 이득, 전멸/시간 통과, 회복 구역의 지속 회복을 검사합니다.
Generate Revised Events 메뉴는 에셋을 위 기본 수치로 덮어씁니다.
구 Stages 에셋은 보관되어 있으며 실제 Game은 StagesV2의 9개 선택지만 사용합니다.

추가 조정: 이벤트 회복약 지급 선택지 4곳에서 2곳으로 축소 (5번 파랑/6번 빨강 각 1개).
좀비 속도 4.5 (플레이어 달리기 5.5 미만), 목각인형 속도 2.8, 골렘 공격력 35.
회복약 줍기 묶음 기본값은 1개이며, 테스트 씬과 프리팹에 반영했습니다.
