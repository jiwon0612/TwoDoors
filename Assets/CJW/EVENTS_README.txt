전투 이벤트 — 현재 적용 규칙

- 모든 18개 선택지는 적 전원 처치해야 통과합니다.
- 시간 경과, 버튼 누르기, 비용 지급만으로 통과하거나 단계를 건너뛸 수 없습니다.
- 체력/아이템 비용은 입장 시 적용하며, 보급도 입장 시 지급하고, 적을 전원 처치하면 통과합니다.
- 선택지 쌍의 순서와 문 색상은 매 판 무작위이며 마지막은 탈출 쌍입니다.
- 실제 통과한 방 수에 따라 적 위협 예산이 9 + 1.8 × 통과 수로 증가합니다.
- 골렘 가중치 3, 원거리 목각인형 2.2, 좀비 1.5. 어두운 방/입장 비용 방은 수를 줄이고 회복 구역/보상 방은 늘립니다.
- 적 수는 최대 14. 원본 에셋 대신 런타임 복제본의 수치를 조절합니다.

적
- 목각인형 복귀: 체력 150, 속도 4.2, 원거리 피해 20, 사거리 14m, 공격 간격 1.8초, 선딜 0.6초.
- 목각인형은 5~11m 거리를 유지하며 주황색 투사체(속도 12m/s)를 발사합니다. 가까우면 후퇴하고 시야가 막히면 추적합니다. 벽과 적이 투사체를 막으며 회피 가능합니다.
- 좀비: 체력 200, 이동 속도 5.76, 공격력 25, 선딜 0.65초 + 공격 후 정지 1초.
- 골렘: 체력 500, 이동 속도 3.2, 공격력 50, 선딜 0.9초 + 공격 후 정지 1초.
- 좀비/골렘은 거리 제한 없이 추격하지만 공격 전조와 공격 후 1초 동안 멈춥니다. 공격 방향은 전조 시작 시 고정되며 정면 240도 안에서 타격합니다. 타격 반경은 좀비 4.6m / 골렘 4.5m이며, 공격 시작 거리는 1.9m / 2.3m로 유지합니다.
- 공격에는 사거리와 시야 확인이 필요합니다. 벽 너머로 피해를 주지 않습니다.
- 권총 피해량 50. 기관총 25, 샷건 8×18, 마체테 65 다중 타격. 플레이어 달리기 속도 9.8.
- 적 체력은 조준 시 숫자 표시 대신 머리 위 체력 바로 표시합니다. 사망하면 숨깁니다.

보상
- 아이템 지급 선택지는 18개 중 10개. 공성전에는 샷건+탄약 14, 암전에는 손전등+마체테+탄약 7, 탄약 공방에는 기관총+탄약 30을 입장 시 지급합니다.
- 체력 감소 방에는 총기를 지급하지 않습니다.
- 회복 구역은 초당 8, 누적 제한 없이 최대 체력까지 회복합니다.
- 클리어 아이템 보상은 제거했고 기존 수량을 전부 입장 보급에 합쳤습니다. 거래 탄약은 예비 탄약을 사용합니다.

화면
- 단계 진입 배너는 타이틀 Y=100, 효과 설명의 상단 Y=25로 분리합니다.
- 타이틀 영역과 설명 영역 사이에 30 UI 단위 간격을 확보합니다.
- 타이틀과 설명은 같은 카드로 페이드/이동하며 서로 겹치지 않습니다.

검증: Tools > TwoDoors > Validate Event Balance.
18개 이벤트, 전멸 조건, 시간 경과 통과 금지, 원거리 목각인형 포함, 보상 비중, 단계별 난이도/원본 불변을 검사합니다.
Generate Revised Events로 원본 이벤트 에셋을 갱신할 수 있습니다.

스태미나: 체력 바 아래 파란 바. 달리기 5초에 소진, 5초에 완충. 완전히 소진하면 완충까지 달리기 잠금. 걷거나 멈추면 회복하며 일시정지 중에는 변하지 않습니다.

문 설명에서는 [섬멸] 접두어와 보유 한도 안내를 제거했습니다. 걷기/달리기의 전조 중 후퇴 및 횡이동 거리로 실제 타격 판정을 검증했습니다.
