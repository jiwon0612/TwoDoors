이벤트 개편 — Game.unity / StagesV2

현재 게임은 9단계, 각 단계 빨강/파랑 2개 선택지를 사용합니다.
구 Stages 에셋은 보관되어 있지만 Game의 진행 목록과 생성기에서 제외했습니다.
미구현 시선 정지 설명과 비슷한 좀비 생존/치료 강도 이벤트를 교체했습니다.

1. 무장할 대가: 체력 25 지불 + 권총/탄약 70 / 권총/탄약 14 + 목각인형 4마리 18초, 회복약 2 보상
2. 떼거리 vs 공성전: 목각인형 8마리 12초 + 탄약 35 / 골렘 3마리 50초, 회복약 2 보상
3. 빛을 살 것인가: 정전 + 손전등 + 목각인형 6마리 22초, 탄약 70 보상 / 체력 30 지불 즉시 통과
4. 야전 병원: 골렘 2마리 35초 + 구역 안 초당 8 회복 / 체력 20 지불 + 회복약 4
5. 보급품 통행료: 회복약 2 지불하고 다음 단계 건너뛰기 / 골렘 2 + 목각인형 4마리 45초, 회복약 3 보상
6. 탄약 환전소: 예비 탄약 28 지불 + 회복약 3 / 목각인형 6 + 좀비 2마리 30초, 입장 탄약 14 + 통과 탄약 84
7. 달리거나 지불하거나: 정전 + 손전등 + 목각인형 5마리, 버튼 3개 작동 / 체력 35 지불 + 탄약 42 + 회복약 1
8. 피의 보급 상자: 체력 55 지불 + 탄약 105 + 회복약 4 / 좀비 3 + 골렘 2 + 목각인형 4마리 55초, 탄약 35 + 회복약 1 보상
9. 최후의 탈출: 회복약 3 지불 즉시 탈출 / 골렘 3 + 목각인형 6마리 60초, 입장 탄약 56

전투는 전원 처치 또는 시간 만료 중 먼저 충족한 조건으로 통과합니다.
버튼 방은 버튼 3개 작동 또는 전원 처치로 통과합니다 (시간 제한 없음).
적 없는 시간제 이벤트를 추가하면 적 0마리라는 이유로 즉시 완료되지 않습니다.
통과 시 남은 적과 조명/회복 구역 등 방 효과를 정리합니다.
보상은 통과할 때만 1번 지급하고, 사망/중단 시에는 지급하지 않습니다.
아이템 보급/보상은 인벤토리 보유 한도까지 지급합니다. 소지품은 다음 단계에 유지됩니다.
지불 아이템이 부족하면 일부만 빼앗지 않고, 문 설명의 대체 체력 비용을 적용합니다:
5번 빨강 50, 6번 빨강 40, 9번 빨강 65. 비용으로 사망하면 통과/보상을 받을 수 없습니다.
예비 탄약만 거래에 사용하며 장전된 탄약은 유지합니다.

Game 씬에 인벤토리 UI도 연결했습니다. Tab으로 열어 아이템을 사용합니다.
에디터 메뉴 Tools > TwoDoors > Apply Revised Events To Game으로 기본 구성을 다시 적용합니다.
이 메뉴는 StagesV2 기본 수치를 덮어쓰므로 수치를 개별 조정한 뒤에는 재실행하지 마세요.
